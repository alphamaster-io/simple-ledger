# SimpleLedger: Small Business Accounting Workbook

> Know where your money goes, know how much you earn, and understand your business finances from one simple Excel workbook.

SimpleLedger is a sellable Excel product: a double-entry bookkeeping system that a non-accountant can run from three input sheets, with a dashboard, P&L, balance sheet, cash flow, AR/AP aging, trial balance and ledger. Everything is calculated from the entries, and the books check themselves.

This repository **generates** the workbook from Python (`openpyxl`) and **tests** it by recalculating it in LibreOffice and comparing every figure with an independent reference implementation of the accounting rules.

## Get the workbook

| File | What |
|---|---|
| `dist/standard/SimpleLedger-Small-Business-Accounting.xlsx` | The product, blank and ready to use |
| `dist/standard/SimpleLedger-Sample-Business-Data.xlsx` | Demo: "Sunrise Bakery & Café", 9 months of data, VAT on |

Open in Excel 2010+ / Microsoft 365. Formulas calculate on open. No macros.

## How it works

```text
SETUP · COA · CUSTOMERS · VENDORS            master data
TRANSACTIONS · AR · AP                       user input (each row computes its own debit/credit, ⛔/⚠ checks)
        └──────────► JOURNAL                 every valid posting, stacked
                       └──► CALC             balance per account × fiscal month
                              └──► PNL · BALANCE_SHEET · CASH_FLOW · MONTHLY_SUMMARY · TRIAL_BALANCE · LEDGER
                                     └──► DASHBOARD
```

- Users pick a **Type** (Money In, Money Out, Customer Payment, Bill Payment, Transfer, Owner Investment, Owner Draw, Adjustment) and a **Category**. Debits and credits are automatic.
- Rows with errors are flagged ⛔ and kept out of the books. Warnings ⚠ are posted. The Dashboard's Data Health panel summarises both.
- Optional VAT/GST tracking. AR/AP with partial payments, terms and aging. Any fiscal-year start month.
- Excel-2010 function set only (no XLOOKUP/FILTER/LET/OFFSET/INDIRECT) for maximum compatibility.

Read more: [`docs/accounting-model.md`](docs/accounting-model.md) (rules) · [`docs/formula-spec.md`](docs/formula-spec.md) (implementation) · [`docs/product-spec.md`](docs/product-spec.md) · [`docs/user-guide.md`](docs/user-guide.md).

## Develop

```bash
sudo apt-get install -y libreoffice-calc     # formula engine used by the tests
pip install -e ".[dev]"

python tools/make_sample_data.py             # regenerate the demo data (deterministic)
python -m simpleledger.build                 # build dist/standard/*.xlsx
python -m pytest                             # about 4 min: builds and recalculates 12 data sets
python tools/recalc.py in.xlsx out.xlsx      # recalculate any workbook (for previews and screenshots)
python tools/package.py                      # assemble the customer download bundle (dist/package/)
```
